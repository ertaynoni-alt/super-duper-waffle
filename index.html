Demo Editor

Загрузи запись матча CS2 (.dem) или сжатый архив FACEIT (.dem.zst) и укажи свой игровой ник.

Как обрабатываются .dem.zst: архивы FACEIT сжаты алгоритмом Zstandard. Файлы не сохраняются в localStorage. В основном режиме .dem.zst передаётся на сервер, где распаковывается в .dem, проверяется по заголовку Source 2 (PBDEMS2) и передаётся парсеру CS2 demo. Для небольших архивов (до 95 МБ) также доступна локальная проверка/распаковка через Zstandard Web Worker без блокировки интерфейса.

FACEIT Match Analyzer

Сохраняй ссылки на матчи FACEIT и свой игровой никнейм в списке задач. Здесь ведётся только учёт матчей.

Важно: доступ к FACEIT Downloads API пока не подключён. Демо-файлы автоматически не скачиваются, убийства по демо не парсятся и анализ не выполняется. Если вы уже скачали демо вручную в формате .dem.zst или .dem, загрузите его во вкладке Demo Editor.
